# Security Policy

## Supported Versions

Currently, only the latest version on the `main` branch is actively supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| > 1.0   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

**DO NOT** open a public issue for a security vulnerability. 

If you discover a security vulnerability within Anon (e.g., DNS leaks, iptables bypass, routing failures), please report it privately:

1. **Email:** Send your report directly to `egcaem000@gmail.com`.
2. **Include Details:** Provide a clear description of the vulnerability, steps to reproduce it, and the potential impact.
3. **Response Time:** We will acknowledge receipt of your vulnerability report within 48 hours and strive to send you regular updates about our progress.

Thank you for your responsible disclosure and for helping keep Anon secure for everyone.
